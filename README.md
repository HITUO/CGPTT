## 每道题的收录标准

每道正式收录的题目尽量包含：

1. 题目信息：平台、题号、标题、难度（有可靠信息时填写）。
2. 题目描述：整理后的完整题意、输入格式、输出格式和数据范围；注明原题链接。
3. 解题思路：从观察、关键性质到算法选择，逐步解释。
4. 正确性说明：解释算法为什么正确。
5. 复杂度分析：时间复杂度和空间复杂度。
6. C++ 代码：完整、可编译，尽量采用清晰易读的写法。
7. 易错点：边界、数据类型、初始化和常见错误。
8. 相关知识与练习：适合时补充知识点和相似题。

> 题面以原题为准。整理时保留原题链接，不凭空补充题目条件；若题面信息不完整，会标注待确认。

## 维护约定

- 按题目主要考查的知识点归档，必要时添加交叉标签。
- 文件名采用“平台-题号-简短标题.md”的形式，尽量使用英文或拼音，避免路径兼容问题。
- 每道题的 Markdown 题解与 C++ 源代码分开保存，方便阅读和编译。
- 更新已有题目时保留原有有效内容，并在必要时修正错误。
- 新题收录后同步更新对应分类目录。
