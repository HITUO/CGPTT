# C++ 常用算法模板库

本目录面向 **C++17 / 洛谷 / OI 与算法竞赛**，集中保存可复用模板。模板以竞赛中常见、实用、容易迁移为标准，不追求把冷门算法堆在一起。

## 文件

- [C++17 综合模板源码](cpp17-template.cpp)：单文件合集，包含常用基础、数据结构、图论、字符串、数学模板。可作为个人起步模板，再按题目需要删减。
- [C++17 进阶模板源码](advanced-template.cpp)：树链剖分、可持久化线段树/主席树、Treap、Dinic、二分图匹配、点分治、莫队、AC 自动机、Manacher、后缀数组、高斯消元、矩阵快速幂。
- [题解 Markdown 模板](problem-template.md)：整理题目时使用。

## 使用方式

1. 建议先通读分类说明，再复制当前题目真正需要的模板。
2. 不要不加思考地把所有模板都粘进每一道题；这会增加编译时间、命名冲突和调试难度。
3. 本仓库源码采用 C++17。若题目平台只支持 C++14 或更早版本，需要检查结构化绑定等较新语法。
4. 数组大小、整数类型、取模数、无穷大、图是否有向、边权是否非负，都必须根据题目修改。
5. 线段树、图论等模板的下标约定在代码注释中标明；使用前先确认题目下标范围。

## 推荐学习顺序

基础输入输出与 STL → 前缀和/差分/二分 → 栈队列/单调结构 → 并查集/树状数组 → 线段树 → BFS/DFS → 最短路/MST/拓扑排序 → DP → 字符串 → 数论 → LCA/SCC 等进阶图论。

> 说明：算法模板是可复用的代码骨架，不代表每道题都能直接套用。尤其是懒标记线段树、强连通分量、LCA 等，必须理解维护的信息和适用条件。
