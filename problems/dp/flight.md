# 小鸟飞行（flight）

- 题目名称：小鸟飞行
- 题目编号：flight
- 分类：动态规划 / 数据结构
- 标签：DAG 最短路、区间 DP、滑动窗口、单调队列、线段树、坐标压缩
- 单只鸟：朴素做法 (O(nk))，优化做法 (O(n\log n))
- 全部询问：优化做法 (O(qn\log n))
- 空间复杂度：(O(n))

> 原题链接：用户提供题面，未提供可验证的原题网址。

## 一、题目描述

有 (n) 棵树从左到右排列，第 (i) 棵树的高度为 (d_i)。一只鸟从第 1 棵树出发。当它位于第 (j) 棵树时，可以飞到第 (j+1) 至第 (j+k) 棵树中的任意一棵，然后休息。

若落点高度大于等于起点高度，这一段飞行使疲劳值增加 1；否则疲劳值不增加。对每只鸟，求到达第 (n) 棵树时疲劳值的最小值。

输入包含树的数量 (n)、高度序列，以及 (q) 只鸟各自的最大跳跃距离 (k_i)。

数据范围：

[
2\le n\le 10^6,\quad 1\le d_i\le 10^9,\quad
1\le q\le25,\quad 1\le k_i<n
]

原题说明使用 `flight.in` / `flight.out` 文件输入输出；提交到使用标准输入输出的平台时，不需要启用 `freopen`。

## 二、做法一：朴素动态规划（(O(nk))）

### 1. 状态定义

固定一只鸟，最大跳跃距离为 (k)。

设：

[
dp[i]=\text{从第 1 棵树到达第 }i\text{ 棵树的最小疲劳值}
]

初始状态：

[
dp[1]=0
]

### 2. 状态转移

从第 (j) 棵树可以跳到第 (i) 棵树，当且仅当：

[
i-k\le j<i
]

这一跳的疲劳代价是：

[
w(j,i)=
\begin{cases}
1,&d_i\ge d_j\\
0,&d_i<d_j
\end{cases}
]

因此：

[
\boxed{
dp[i]=\min_{j=\max(1,i-k)}^{i-1}
\left(dp[j]+[d_i\ge d_j]\right)
}
]

其中 ([P]) 表示条件 (P) 成立时取 1，否则取 0。

最终答案为 (dp[n])。

### 3. 复杂度

每个位置最多枚举 (k) 个前驱，因此单次询问：

- 时间复杂度：(O(nk))
- 空间复杂度：(O(n))

当 (n\le200) 时足够；但 (n\le10^6)，且最多有 25 次询问，不能作为最终算法。

## 三、做法二：拆成两个区间最小值（为数据结构优化做准备）

转移式中，前驱 (j) 只通过高度与 (d_i) 的大小关系影响代价。

分成两类：

**第一类：前驱高度不超过当前高度**

若 (d_j\le d_i)，这一跳代价为 1：

[
\min_{j\in[L,i-1],\ d_j\le d_i}dp[j]+1
]

**第二类：前驱高度高于当前高度**

若 (d_j>d_i)，这一跳代价为 0：

[
\min_{j\in[L,i-1],\ d_j>d_i}dp[j]
]

其中 (L=\max(1,i-k))。

所以：

[
\boxed{
dp[i]=\min\left(
1+\min_{\substack{L\le j<i\\d_j\le d_i}}dp[j],
\min_{\substack{L\le j<i\\d_j>d_i}}dp[j]
\right)
}
]

这就是一个二维限制下的最小值查询：
- 下标 (j) 必须位于滑动窗口 ([L,i-1])；
- 高度 (d_j) 必须落在当前高度对应的一侧。

只按下标建普通线段树，或只按高度建普通线段树，都无法直接同时处理这两个限制。

## 四、做法三：坐标压缩 + 每个高度一个单调队列 + 线段树（(O(n\log n))）

这是适合完整数据范围的做法。

### 1. 高度坐标压缩

高度最大可达 (10^9)，但只有 (n\le10^6) 个高度值。

将所有 (d_i) 排序去重，用其离散排名 (r_i) 代替原高度。这样：

[
d_j\le d_i\iff r_j\le r_i
]

[
d_j>d_i\iff r_j>r_i
]

### 2. 线段树维护什么？

线段树的下标是压缩后的高度排名。

每个叶子 (r) 维护：

> 当前滑动窗口中，高度排名恰好为 (r) 的树，其 (dp) 值的最小值。

于是对当前树 (i)，只需要查询：

- 排名区间 ([1,r_i]) 的最小值，代表高度不超过 (d_i) 的前驱；
- 排名区间 ([r_i+1,M]) 的最小值，代表高度高于 (d_i) 的前驱。

转移为：

[
dp[i]=\min\left(
query(1,r_i)+1,
query(r_i+1,M)
\right)
]

空区间的查询结果设为无穷大。

### 3. 如何维护每个高度的叶子值？

如果每个高度都用 multiset，虽然可以实现，但常数和内存开销较大。这里可以使用**单调队列**。

对同一个高度，按照下标从小到大的顺序加入候选树。队列中保存 ((index,dp[index]))，并保持队列内 (dp) 值单调递增。

加入新候选 (j) 时：

- 如果队尾的 (dp\ge dp[j])，就弹出队尾；
- 然后把 ((j,dp[j])) 加到队尾。

为什么可以弹出？被弹出的旧候选下标更小、(dp) 值不小于新候选。新候选不仅当前不更差，而且会比旧候选更晚离开滑动窗口，因此旧候选永远不可能成为该高度的最优值。

当窗口左端点右移时，如果队首下标已经小于 (L)，就弹出队首。

这样，每个候选最多入队一次、出队一次。

### 4. 处理每个位置的顺序

对于位置 (i=2,3,\ldots,n)，当前允许的前驱窗口为：

[
[L,i-1],\qquad L=\max(1,i-k)
]

依次执行：

1. 删除所有下标小于 (L) 的过期候选；
2. 将刚刚计算完成的 (i-1) 号位置加入对应高度的单调队列；
3. 在线段树上查询高度排名 ([1,r_i]) 和 ([r_i+1,M])；
4. 计算 (dp[i])。

注意：必须先保证窗口中只包含合法前驱，再查询。位置 (i) 本身不能加入自己的前驱集合。

### 5. 复杂度

每个位置最多进行常数次线段树单点修改和两次区间查询：

- 时间复杂度：(O(n\log n)) / 每只鸟；
- 空间复杂度：(O(n))。

共有 (q\le25) 只鸟，总时间复杂度：

[
\boxed{O(qn\log n)}
]

总空间复杂度为 (O(n))，每只鸟处理完后即可复用数组和数据结构。

## 七、正确性说明

### 朴素 DP

任意到达位置 (i) 的合法路径，其最后一步必然来自区间 ([\max(1,i-k),i-1]) 中的某个位置 (j)。最后一步的代价恰为 ([d_i\ge d_j])。枚举所有合法前驱并取最小值，覆盖了所有可能的最优路径，因此转移正确。

### 数据结构优化

对固定位置 (i)，合法前驱仍然恰为滑动窗口 ([L,i-1])。按高度拆分后，所有前驱被不重不漏地划分为 (d_j\le d_i) 与 (d_j>d_i) 两类，分别增加 1 和增加 0，故两次区间最小值查询的较小值就是原转移。

对同一高度，单调队列删除的候选都被一个下标更大且 (dp) 值不大的候选支配。支配者进入窗口不晚于被支配者离开窗口，因此被删除候选在未来任何时刻都不可能成为窗口最小值。队首始终是该高度当前窗口内的最小 (dp)。

线段树维护各高度队首的最小 (dp)，所以两个高度区间查询分别准确返回两类合法前驱的最小 (dp)。因此优化算法与朴素转移完全等价，结果正确。

## 八、易错点

1. **疲劳增加条件是大于等于。** 高度相等时也要加 1，不能误写成严格大于。
2. **最大跳跃距离是树的下标差。** 从 (j) 可以到 (j+1\) 至 (j+k)，不是最多经过 (k) 棵中间树。
3. **窗口左端点是 (\max(1,i-k))。**
4. **高度区间必须正确划分。** 代价为 1 的部分是排名 ([1,r_i])，代价为 0 的部分是 ([r_i+1,M])。
5. **单调队列按 (dp) 值递增维护，不是按高度维护。** 每个队列本身对应一个固定高度。
6. **相等的 (dp) 也可以弹出旧队尾。** 新候选下标更大，过期更晚，保留新候选即可。
7. **空区间返回 INF。** 例如当前高度已是最大排名时，([r_i+1,M]) 是空区间。
8. **多组鸟的询问要独立计算。** 每只鸟的 (k) 不同，滑动窗口不同，不能直接复用上一只鸟的 (dp)。
9. **输入样例排版需要核对。** 当前收到的样例行号和数据换行混杂，不能可靠确定原始样例，题解不擅自补写样例输出。

## 九、方法对比

| 方法 | 单次询问时间 | 空间 | 适用场景 |
|---|---:|---:|---|
| 朴素 DP | (O(nk)) | (O(n)) | 小数据、验证 |
| 高度分组 + 单调队列 + 线段树 | (O(n\log n)) | (O(n)) | 完整数据 |

建议先独立写出朴素 DP，确认转移式没有问题，再实现优化版本。真正的难点不是线段树本身，而是发现：**固定高度的候选可以用单调队列维护，而所有高度的最小值可以交给线段树做区间查询。**
