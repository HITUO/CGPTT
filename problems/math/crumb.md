# 小鱼干摆放（crumb）

- 题目名称：小鱼干摆放
- 题目编号：crumb
- 分类：数学与数论
- 标签：数学推导、贪心思想、二分答案、整数边界
- 时间复杂度：公式做法 (O(1))；二分做法 (O(\log k))
- 空间复杂度：(O(1))

> 原题链接：题目由用户提供。当前未提供可验证的原题网址。

## 一、题目描述

给定 (n) 个盘子，每个盘子可以放 (0)、(1) 或 (3) 条小鱼干。要求恰好放入 (k) 条小鱼干，并使空盘子的数量最少。如果不存在合法方案，输出 (-1)。

### 输入格式

第一行输入测试组数 (T)。接下来 (T) 行，每行输入两个整数 (n,k)，分别表示盘子数量和小鱼干总数。

原题说明使用文件输入输出：从 `crumb.in` 读入，输出到 `crumb.out`。

### 输出格式

每组数据输出一个整数，表示最少空盘子数；无方案时输出 (-1)。

### 数据范围

[
1\le T\le 2\times 10^5,\qquad 1\le n,k\le 10^9
]

## 二、核心转化

设：

- (x)：放了 3 条小鱼干的盘子数；
- (y)：放了 1 条小鱼干的盘子数；
- (m=x+y)：非空盘子数。

由题意：

[
3x+y=k,\qquad x+y=m
]

两式相减：

[
2x=k-m\quad\Longrightarrow\quad m=k-2x
]

我们要让空盘子最少，也就是让非空盘子数 (m) 最大。因为 (m=k-2x)，所以等价于让 (x) 尽可能小。

合法摆放还要求：

[
0\le x\le\left\lfloor\frac{k}{3}\right\rfloor
]

并且非空盘子不能超过总盘子数：

[
k-2x\le n
]

## 三、做法一：数学公式（(O(1))）

由 (k-2x\le n)，得到：

[
x\ge\left\lceil\frac{k-n}{2}\right\rceil
]

再结合 (x\ge0)，最小候选值为：

[
\boxed{x=\max\left(0,\left\lceil\frac{k-n}{2}\right\rceil\right)}
]

当 (k>n) 时，正整数的向上取整可用整数运算：

[
\left\lceil\frac{k-n}{2}\right\rceil
=\frac{k-n+1}{2}
]

因此代码中：

[
x=\begin{cases}
0,&k\le n\\
(k-n+1)/2,&k>n
\end{cases}
]

如果 (x>\lfloor k/3\rfloor)，说明即使尽量多使用 3 条装的盘子，也无法在 (n) 个盘子内放下恰好 (k) 条小鱼干，答案为 (-1)。

否则：

[
m=k-2x
]

[
\boxed{ans=n-m=n-k+2x}
]

## 四、做法二：二分答案（(O(\log k))）

仍然二分 (x)，即放 3 条小鱼干的盘子数量。

(x) 的取值范围是：

[
0\le x\le\left\lfloor\frac{k}{3}\right\rfloor
]

当确定 (x) 后，非空盘子数为 (m=k-2x)。我们需要满足：

[
k-2x\le n
]

观察这个条件：随着 (x) 增大，(k-2x) 单调减小。因此：

- 当条件不满足时，说明 (x) 太小，需要向右搜索；
- 当条件满足时，记录当前答案，并继续向左搜索，寻找更小的 (x)。

我们要找的是第一个满足 (k-2x\le n) 的 (x)。

如果区间右端点 (\lfloor k/3\rfloor) 都不满足条件，则无解，输出 (-1)。

找到最小可行 (x) 后，仍然计算：

[
ans=n-(k-2x)
]

## 五、正确性说明

任意合法方案都可以由 (x) 个放 3 条的盘子和 (y=k-3x) 个放 1 条的盘子组成，其非空盘子总数为 (m=k-2x)。

为了使空盘子数 (n-m) 最小，必须最大化 (m)，也就是最小化 (x)。

合法的 (x) 必须满足：

[
0\le x\le\lfloor k/3\rfloor,\qquad k-2x\le n
]

公式做法直接求出满足第二个不等式的最小非负整数 (x)，再检查它是否不超过上界，因此得到的就是最优解；若超过上界，则不存在合法方案。

二分做法利用 (k-2x\le n) 关于 (x) 的单调性，找出满足条件的最小 (x)，与公式做法得到同一个最优值。因此两种做法都正确。

## 六、复杂度分析

| 做法 | 时间复杂度 | 额外空间复杂度 |
| --- | --- | --- |
| 数学公式 | (O(1)) / 每组 | (O(1)) |
| 二分查找 | (O(\log k)) / 每组 | (O(1)) |

最多有 (2\times10^5) 组数据，且 (k\le10^9)，两种做法都能满足要求。公式做法更简洁，二分做法更适合练习单调性与二分查找。

## 七、易错点

1. **不能只检查 (k\le3n)。** 例如两个盘子最多能放 6 条，但恰好放 5 条仍然不可能；每个盘子只能放 0、1、3 条，组合受到限制。
2. **必须检查 (x\le\lfloor k/3\rfloor)。** 这保证剩余的小鱼干可以由放 1 条的盘子承载。
3. **二分要找最小可行的 (x)。** 因为 (x) 越小，使用的非空盘子越多，空盘子越少。
4. **向上取整要处理好边界。** 只有在 (k>n) 时才使用 ((k-n+1)/2)。
5. **数据范围较大。** 本题 (10^9) 以内，32 位有符号整数足够；使用 `long long` 也没有问题。
6. **文件输入输出。** 若评测环境严格要求文件读写，可在代码中启用 `freopen("crumb.in","r",stdin)` 和 `freopen("crumb.out","w",stdout)`；若平台使用标准输入输出，则不要启用。
